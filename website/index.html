def count_vowels(word):
    count = 0
    for letter in word:
        if letter in "aeiouAEIOU":
            count += 1
    return count

Opening it for the first time

Windows says "Windows protected your PC"

Windows shows this for new apps it doesn't know yet. Click More info, then Run anyway. You only need to do this once.

Mac says it can't verify the app
  1. Open System Settings → Privacy & Security.
  2. Scroll down to the message about sudopy and click Open Anyway.
  3. Open the app again and click Open.

You only need to do this once.
